Agent Definition Format

ClaudeKit-style markdown agent with YAML frontmatter. Placed in claude/agents/. Each file is one agent.

🏛️ Software Architect
Source: agency-agents engineering-software-architect
Graph roles: scouter, planner, synthesizer
Default model: opus
Core: System design, DDD, trade-off analysis, ADRs
Key deliverables: Architecture decision records, bounded context maps, system evolution strategy
Evidence: [architecture_decisions, trade_offs, context_map]
👁️ Code Reviewer
Source: agency-agents engineering-code-reviewer
Graph roles: worker, verifier
Default model: sonnet
Core: Security, maintainability, performance review
Key deliverables: Findings list with severity, remediation steps
Evidence: [findings, severity, remediation, lines_affected]
🧪 QA Engineer
Source: agency-agents testing-evidence-collector + model-qa
Graph roles: verifier, worker
Default model: haiku (verification is cheap)
Core: Test case design, test execution, bug finding
Key deliverables: Test plan, pass/fail results, bug reports
Evidence: [test_results, bug_reports, coverage_gaps]
📊 Data Engineer
Source: agency-agents engineering-data-engineer
Graph roles: worker, scouter
Default model: sonnet
Core: Data pipelines, schema design, ETL, quality
Key deliverables: Schema changes, migration plans, data quality reports
Evidence: [schema_changes, data_quality, migration_plan]
🎨 UI Designer / UX Researcher
Source: agency-agents design-ux-researcher + design-ui-designer
Graph roles: worker, synthesizer
Default model: sonnet
Core: User research, wireframes, design systems, accessibility
Key deliverables: Personas, journey maps, component specs
Evidence: [design_specs, accessibility_audit, user_flows]
🔧 Agents Orchestrator
Source: agency-agents specialized-agents-orchestrator
Graph roles: scouter, synthesizer
Default model: opus
Core: Multi-agent coordination, task decomposition, quality gates
Key deliverables: Task breakdown, agent assignments, orchestration plan
Evidence: [task_breakdown, agent_assignments, orchestration_log]
📝 Document Generator
Source: agency-agents specialized-document-generator
Graph roles: synthesizer, worker
Default model: sonnet
Core: Technical docs, reports, runbooks, API references
Key deliverables: Markdown reports, structured documentation
Evidence: [report, executive_summary, recommendations]
➕ Custom Agents
Users can add agents to claude/agents/
Follow same format: YAML frontmatter + markdown body
Available in graph.yaml: immediately after adding
Override default model: per-node in graph.yaml
Community agents: install from agency-agents repo
