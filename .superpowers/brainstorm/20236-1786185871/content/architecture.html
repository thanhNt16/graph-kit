Data Flow: User Session

1. /gk:init-graph --template diamond
   → generates graph.yaml in project root
2. User edits graph.yaml (assign agents, define inputs)
3. /gk:brainstorm — agent asks clarifying questions, updates graph.yaml
4. /gk:validate — syntax + topology + agent binding + evidence check
5. /gk:compile → .claude/workflows/graph.workflow.js
6. /gk:run → invokes Claude Code Workflow tool
   → agents execute nodes, evidence collected, status tracked
7. /gk:evidence → report of what the graph produced
