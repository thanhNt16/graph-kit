What gk CLI v2 Does

Kit Installation

  • gk init — copy claude/ to .claude/
  • gk new --dir X — scaffold new project + init
  • metadata.json tracks version for upgrades

Graph Lifecycle

  • gk validate — check graph.yaml
  • gk compile — YAML → .workflow.js
  • gk graph list — show topologies
  • gk graph inspect — topology contract

NOT in gk CLI v2

  • workflow start/next/submit/execute
  • leases, checkpoints, events
  • state machine, expression engine
  • merges, run persistence

All runtime concerns moved to Claude Code Workflows. gk is a compiler + installer only.
