# GraphKit Audit — 2026-09-18

> **Historical audit (2026-09-18).** Findings are a snapshot of that date. Most have since been fixed across P0–P4 (validation tier unification, compile runtime removed for planGraph+exec, CBM bridge deleted, memory shrink); command names and counts below reflect the old surface.

Six-agent parallel audit: 4 code audits (core/schemas, CLI, memory, infra) + 2 research sweeps (graph-engineering orchestration, memory/context engineering). All findings cite file:line.

## Verdicts

- **Validation layer**: trustworthy for graph shape, leaky at the seams. Zod core is solid (strict objects, cross-refs, cycle detection, template cross-validation; repo's own graph.yaml parses clean). Compiler determinism claim VERIFIED. But enforcement is two-tier and the `graph switch`/load path only runs tier one.
- **CLI**: solid skeleton — envelope contract, parity probes, unknown-leaf rejection show care. Rot is in the second hand-maintained surface description (registry + manifest) that has already diverged from the code.
- **Memory subsystem**: delivers real, measurable value; speculation confined to edges. Core loop is sound and cheap (~10.8ms/query at 300 entries, zero model calls). Keep it; fix the duplicated retriever.
- **Onboarding**: README alone gets a newcomer to a gated diamond run, except the pasted CLI reference is stale (wrong version, 4 missing commands) and nothing warns that 7 commands need an unpublished MCP backend.

## Research — techniques worth adopting (ranked by impact)

### Orchestration (from LangGraph, Temporal, LLMCompiler, Anthropic, Cognition)

1. **Checkpoint-per-wave durable resume** (LangGraph checkpointer): persist per-node status/outputs/wave after every wave; `gk resume <run-id>` re-runs only incomplete nodes. Add retention policy.
2. **Event-sourced replay** (Temporal): model a run as append-only event log (node started/emitted/edge routed); resume = replay without re-invoking completed LLM calls; log doubles as evidence input.
3. **Map-reduce fan-out** (LangGraph Send API): `map:` node type — item source from upstream output, child node, reduce strategy (append/merge/vote). Replaces hand-enumerated parallel lists.
4. **Human-in-the-loop gates** (LangGraph interrupts): `gate:` node kind emitting structured approval payload, suspending run; stable gate ids, id→decision resume map, idempotent pre-gate work.
5. **Per-node context budgeting** (Anthropic context engineering): `budget:` per node; oversized upstream outputs compacted or spilled to artifact files with reference+digest passed along the edge.
6. **Artifact handoff contract** (Anthropic multi-agent): typed node outputs `{report: file, summary: inline}` — bulky deliverables as artifacts, only references flow through state; gk-validate checks producer/consumer contract.
7. **Declarative retry policies** (Temporal): per-node `retry: {initial_interval, backoff, max_attempts, non_retryable}`; prompt/parse errors non-retryable, transient API errors retry; never retry whole run.
8. **Conditional edges** (LangGraph): `when:` predicates over graph state — static topology, runtime routing; private channels keep scratch out of downstream prompts.
9. **Loop-until-done with evaluator feedback** (Reflexion + Anthropic evaluator-optimizer): exit predicate + max_iterations + inject evaluator feedback text into next iteration's context — the feedback-in-context detail is where measured gains come from.
10. **Speculative dataflow dispatch** (LLMCompiler): dispatch nodes whose inputs are constant/template-only without waiting for full wave barrier — up to 3.7x latency speedup.
11. **Effort tiers** (Anthropic): `effort: light/standard/deep` scaling fan-out width, budgets, loop bounds; default cheap.
12. **Share traces on sequential edges** (Cognition counterweight): pass upstream decision+rationale summary into next node by default; reserve context-isolated fan-out for provably independent work.
13. **Patched versioning for in-flight runs** (Temporal `patched()`): record `graph_version` per node at checkpoint; resumed runs replay with starting version, unstarted nodes pick up edits.

### Memory (from Anthropic, Mem0, Zep/Graphiti, HippoRAG, Letta, A-MEM, Chroma, LongMemEval)

1. **BM25 scoring** (Anthropic contextual retrieval): replace set-overlap with corpus-statistics BM25 (IDF + TF saturation + length norm) × salience — ~20 lines, no new dep.
2. **Write gate** (Mem0 ADD/UPDATE/DELETE/NOOP): similarity gate at consolidate-write time — fold near-duplicates into existing entries (bump count/last_seen) or mark `superseded_by` instead of appending.
3. **LLM importance at write time** (Generative Agents): curator emits importance judgment into `salience` field; deterministic counters modulate rather than invent; sub-floor entries skip the store.
4. **Bi-temporal invalidation** (Zep/Graphiti): schema already has both timelines; make `resolveSuperseded` honor `invalid_at`/`valid_to` written by consolidation on contradiction.
5. **Personalized PageRank over link graph** (HippoRAG): replace single-hop 0.5-penalty expansion with 2-3 iteration PPR seeded by direct hits — ~25 lines, removes arbitrary LINK_PENALTY.
6. **Sleep-time compute** (Letta): extend consolidate to precompute recall-side artifacts (IDF tables, .links.json, index.md) into `.recall-cache.json` — recall becomes O(query) not O(corpus scan).
7. **Relative-score cutoff over fixed k** (Chroma context-rot): drop hits below a fraction of top score — return 2 strong memories rather than 5 with 3 distractors.
8. **Eval harness with knowledge-update/abstention cases** (LongMemEval): gold cases for supersede-only-successor, expired-must-not-rank, and no-match→empty-result; makes scoring changes measurable.
9. **Rerank before injection** (Anthropic): cheap lexical rerank over top-15 full body text before top-k — recovers precision lost by frontmatter-only indexing.
10. **A-MEM link evolution**: build links at write time (not just consolidation); propagate high-frequency tags from linked neighbors.
11. **Provenance enforcement**: every generated memory's `sources` must cite `run:<id>` or evidence-store keys — makes recall auditable and enables trust-weighted ranking.
12. **JIT identifiers, never inline bodies** (Anthropic): codify in gk-recall contract — inject id+salience+first-line, consumers open what they need.
