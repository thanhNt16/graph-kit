Architecture

Three Layers, Clean Boundary

gk CLI validates and compiles. Claude Code executes. The kit template connects them. No custom state machine — Claude Code's native Workflow tool owns the runtime.

Layer 1 — Kit Template
📦 claude/ directory
Installed by gk init into .claude/. Agents, skills, hooks, rules, schemas, topology templates.
7 agents · 8 skills · 3 hooks · 3 rules · 6 templates
↓
Layer 2 — gk CLI v2
⚙️ Compiler + Installer
Validates graph YAML against schemas + topology contracts. Compiles to self-contained .workflow.js. Never invokes a model.
gk init → gk validate → gk compile
↓
Layer 3 — Claude Code Runtime
▶️ Workflow Tool
Executes the compiled .workflow.js using agent(), parallel(), pipeline(). Agents run at their declared model tier.
Graph Topologies

Six Canonical Shapes

Each topology is a parameterized .workflow.js template. They compose — a diamond's fan-out can embed an adversarial-verification subgraph.

Diamond
fan-out → reduce → synthesize
Split work to N parallel workers, reduce with deterministic code, synthesize with one high-tier agent.
→ code review · research · migration
Classify-and-Act
route 1 → 1 handler
Classifier inspects input, routes to exactly one handler. Fallback for unmatched inputs.
→ triage · routing · escalation
Adversarial Verification
produce → refute → adjudicate
Producer emits items. Independent refuters with fresh context challenge each. Survivors pass threshold.
→ security audit · fact-check · code review
Loop Until Done
scout → work → dedup → repeat
Scout discovers work, workers process, dedup against seen. Loop until K consecutive empty rounds.
→ discovery · bug sweep · exhaustive search
Generate-and-Filter
generate N → keep best K
Multiple generators propose candidates. Rubric scores in one deterministic pass. Keep top-K.
→ naming · design variants · ideation
Tournament
pairwise elimination
Candidates compete in pairwise judged rounds. One champion emerges.
→ ranking · eval scoring · taste calls
Per-Node Binding

Model Tiering, Tools, Loops, Constraints

Every node carries its own configuration. The scouter runs at opus for deep analysis. The verifier runs at haiku for cheap checks. Workers get their own tools, refs, and internal loops.

sonnetimplementation · review

Session Flow

From Idea to Running Graph

Inside a Claude Code session, the eight skills walk the user through the full lifecycle.

/gk-init-graph → /gk-visualize → /gk-brainstorm → /gk-validate → /gk-compile → /gk-run → /gk-evidence
terminal
# Install the kit $ gk init # Validate + compile $ gk validate --json {"status":"ok","topology":"diamond"} $ gk compile --json {"status":"ok", "compiled":".workflow.js"} # List topologies $ gk graph list ["diamond", "classify-and-act", "adversarial-verification", ...]
